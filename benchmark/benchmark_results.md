# Результаты benchmark

Окружение: Python 3.12.3, Linux x86_64.
Таблица `experiments` с N записями (datasets и models по 5). Время операций над одной записью усреднено по 5 случайным id, SELECT с фильтром и SELECT * по 3 запускам.

| Записей | Файл, КБ | INSERT всех, с | INSERT одной, мс | SELECT *, мс | SELECT WHERE id=?, мс | SELECT WHERE accuracy>0.9, мс | UPDATE по id, мс | DELETE по id, мс | INSERT с ручным id, мс |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1,000 | 49 | 0.05 | 0.051 | 5.3 | 4.5 | 6.3 | 4.8 | 8.7 | 4.4 |
| 10,000 | 480 | 0.52 | 0.052 | 56.5 | 60.5 | 48.2 | 61.3 | 64.5 | 88.9 |
| 100,000 | 4786 | 6.50 | 0.065 | 796.9 | 516.0 | 592.9 | 525.0 | 533.2 | 522.9 |

Поиск, UPDATE, DELETE и проверка дубликата при ручном id идут полным проходом по файлу, поэтому их время растёт пропорционально числу записей. INSERT с авто-ID не зависит от размера таблицы: запись дописывается в конец файла.
